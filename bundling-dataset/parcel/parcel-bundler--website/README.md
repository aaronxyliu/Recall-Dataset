# parcel-bundler/website

Commit `01c63ed0cb880285db774ec7c96f88da24aeaec7`. Build tool: Parcel. Engine: Parcel.

The site is generated by Eleventy and then bundled by Parcel. Git checkouts on Windows may carry CRLF in Markdown, which breaks the Eleventy `sample` shortcode, so the recipe normalizes line endings before building.

From this folder, extract the pinned revision into an empty source directory and run:

```sh
mkdir source
curl -fLsS https://codeload.github.com/parcel-bundler/website/tar.gz/01c63ed0cb880285db774ec7c96f88da24aeaec7 -o source.tar.gz
tar xzf source.tar.gz --strip-components=1 -C source
docker build -f "$PWD/Dockerfile" -t recall70/parcel-bundler--website:01c63ed0cb88 source
docker run --rm -p 127.0.0.1:8080:80 recall70/parcel-bundler--website:01c63ed0cb88
```

Open http://127.0.0.1:8080/.

Observed result: build-verified. The container served the landing route over loopback (HTTP 200) and the script/source-map pair was fetched from the same origin. Browser smoke test pending.
